# Admin web-theme UI update

The admin panel was adjusted to keep the modern dashboard layout while matching the public website brand more closely.

Changes:
- Dark sidebar using the same dark ministry style as the public site.
- Green/emerald and warm gold/amber accents instead of generic purple UI colors.
- Dashboard cards now use website-aligned gradients.
- Admin resource buttons, badges, filters, upload fields, and hover states now use the web theme.
- No .env, .env.local, or .env.example files were changed or deleted.
